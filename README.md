# 🎬 AutoPause for YouTube  
*Smart video pausing for multitaskers*

---

## 📌 Overview  
**AutoPause for YouTube** is a lightweight Chrome extension that automatically pauses YouTube videos when you switch to another tab. It’s perfect for users who tend to multitask or get distracted—no more missing your favorite parts!

---

## ✨ Features

- 🔇 **Auto-Pause:** Instantly pauses the video when you switch tabs  
- ▶️ **Auto-Resume:** Resumes playback when you return  
- 🧠 **Fully Automatic:** Works without any user input  


---

## 🛠 Tech Stack

- **JavaScript** – Core scripting logic  
- **Manifest V3** – Modern and secure extension structure  
- **YouTube DOM Scripting** – Smart video element control
